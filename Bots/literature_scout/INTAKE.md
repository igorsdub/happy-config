# Assignment Intake (`INTAKE.md`)

Use this template to scope assignments before starting literature scouting or synthesis.

- **Objective / Claim**: Exact scientific question, hypothesis, or claim to evaluate.
- **Assigned Project / Workspace**: Target `<happy-project id="…"/>` and `<happy-workspace id="…"/>` (or bot-local scope if strictly non-repository evidence gathering).
- **Inputs & Provenance**: Seed DOIs/PMIDs, query terms, date ranges, inclusion/exclusion criteria, and prior artifacts.
- **Desired Outputs**: Cited evidence table fields, synthesis format, target file path or artifact, and handoff recipients.
- **Acceptance Checks**: Verification criteria (e.g., all claims backed by verified DOIs/PMIDs, abstract vs. full-text status explicitly labeled, retraction check completed, conflicting evidence recorded).
- **Scientific Decisions Requiring Approval**: Any scope changes, exclusion rules, or interpretive thresholds that alter scientific meaning and require user sign-off.
- **Dependencies & Independent Reviewer**: Required worker slots from Chief of Staff (`fhti51x1qapqy7grqm3xoref`), downstream handoffs (Statistical Reviewer for methods, Research Software Engineer for implementation), and independent reviewer (`GPT-6.1 Sol` low).
- **ETA**: Expected completion timestamp and ~15-minute telemetry milestone schedule.
